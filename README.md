# Gasto Control Android

Aplicación móvil desarrollada en Kotlin con Jetpack Compose para registrar y controlar gastos personales.

## Tecnologías
- Kotlin
- Jetpack Compose
- Android Studio
- Gradle

## Funcionalidades (en progreso)
- Registro de gastos
- Visualización de lista de gastos
- Cálculo de total
